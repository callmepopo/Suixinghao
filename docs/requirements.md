# 需求与验收

## 范围

随行号以用户自建Unraid+模块为服务端，网页做基础电话和Key测试，iOS为最终使用入口；源码、部署方式、驱动引用和接口契约公开。HiDeck与第三方驱动保持各自许可。App不携带个人服务地址、网页密码或Key，用户手工配置自己的HTTPS根地址及独立App Key。

首版维持单模块、单通话，不提供公共电话托管、多人并发、任意AT代理、通用模块一键开通；App Store推送relay已有独立Production／Sandbox部署；开发包Sandbox锁屏来电已验，Production／TestFlight未验。网页短信完整收发沿用HiDeck原入口；内嵌网页集中电话测试与Key管理。

## 日常测试与状态记录

流程为AI在同一源码仓库develop开发 → private/testing保存开发签名包、私有配置及手机验收记录 → 手机验收通过后合main → 正式Release候选包TestFlight production验证 → 同一正式构建美区审核与对应GitHub Release。private是隐私分类，不能把它等同测试分支；不维护private内第二份源码。旧archive/legacy只读回退，后续实现只改公共源码仓库。

每批记录版本、源码commit、测试层级和结果，分别写“编译/模拟器/模拟接口/新部署/开发真机/TestFlight/商店审核”。202610094初始批次为开源整理及本机静态/构建验证，不包含签名真机安装、线上变更、真实拨号/短信、production推送或上架验收。实际检查结果见根CHANGELOG，不预填未运行项目为通过。

自行签名需使用匹配的Apple注册身份与描述文件。新身份开发包已确认Sandbox锁屏来电、接听、双向声音及后台通话；原生锁屏免提在修复候选复验仍回退，延期处理，不能记为修复通过。正式包已上传但Production／TestFlight真机与审核仍待完成；旧身份或开发包结果不能代替正式验收。首版免费分发地区为美国、香港、印度、土耳其、菲律宾，不含中国大陆；见 [App Store后续](app-store.md)。


收工检查保持编译、签名／上传、真实手机和商店审核分层记录。2026100915构建21已通过Apple处理VALID，不代表已提交审核；2026100916仅材料闭环，不重建／重标手机、服务或上传包。


接通前音频验收：呼出dialing期间听到模块实际提供的提示／回铃，麦克风上行和录音保持关闭；active后双向声音正常且不重启模块路由；对方忙线／拒接／未接听／用户取消均释放媒体，不把播报视为已接通。至少真机复验忙线播报及正常接通；模块是否提供早期PCM不能由编译或模拟测试证明。

## 0.1.2日常诊断验收

日常自然通话被动采集，不要求刻意复现。验收包含v2/v1/无协商兼容、异常事件时间及帧关联、窗口上限与非法字段拒绝、音量聚合数值、重连隔离及接通前/静音不计入麦克风音量。自动测试与构建不能代替15Pro、SE3覆盖安装和日常通话验收；对方反馈后对照通话时段、录音与日志再定位，诊断更新不代表断音已修复。

## App 0.1.3：短信删除与连接设置

- 短信列表左滑可删除整个 SIM/对方会话（包括未显示的历史）；会话内左滑可删除单条记录。两种操作均先确认，服务成功后刷新；失败不假称成功。删除为 HiDeck 服务历史删除，所有接入设备共享，不能撤回已发送短信，不操作模块存储。
- 设置按「连接配置与电话授权」「当前状态」「历史状态」三类排列，关于与隐私说明进入独立详情。
- 「断开」清理会话与推送登记，保留最近地址、Key及主动断开标记在 ThisDeviceOnly 钥匙串；前后台切换、网络变化、重启均保持断开，点击「连接并验证」恢复。未断开的连接继续自动恢复；更换服务可编辑地址与Key。
- 验收：整会话与单条删除、其他 SIM 不受影响、失败提示、主动断开后配置保留与不自动重连、手工重连与更换服务、SE3三类设置布局。生产数据删除与真机操作由维护者验收，合成测试不替代。

0.1.3验收状态：维护者于2026-10-10确认本轮短信删除、断开重连与设置三类布局验证通过；设备覆盖未逐台报告，Production／TestFlight等既有待验项保持。

## App 0.1.4：拨号页小屏适配与号码清空

- SE3标准显示下，数字键盘和系统／随行号拨号按钮完整可见，按钮位于Tab导航上方。按实际可用宽高适配，大字体或联系人结果增多时内容可滚动，拨号操作保持可达。15Pro布局保持正常。
- 空闲时从后台重新进入App，号码默认空白；首次冷启动同样为空，不恢复上次输入。主动选择通话记录或系统入口带入号码仍可拨号；正在拨号、来电或已接通时不清理通话按键状态。
- 验收：SE3／15Pro分别输入号码、后台再进入检查清空；核对按钮可见可点、通话中DTMF与主动选取号码。模拟器与编译不替代上述真机验收。

## App 0.1.5：外部号码与前台切换顺序

上次号码仅在空闲进入后台且没有待接收外部号码时清空；进入前台、临时失去焦点不清空。外部号码可先于或晚于激活事件到达，两种顺序均保留本次号码，仅填入不自动拨号。需15Pro从实际第三方软件跳转回归、普通后台再进入旧号码为空、通话状态不受影响；模拟回调顺序与编译不代替真机。

0.1.5验收：2026-10-10维护者确认15Pro验证通过，记录外部软件号码交接修复真机通过；不扩大为SE3正式包或此前延期的双机接听协调验收。
