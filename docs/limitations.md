# 当前能力与限制

- 单模块、单通话与单音频所有权；20把Key不等于20路通话。PCM为8kHz、S16_LE单声道，弱网、蓝牙与长通话需逐项真机验证。
- AT接口和模块音频路由必须同时独占；停止脚本会关闭共享UAC和语音FIFO，不能与其他模块语音工具并行使用。进程PID核对不等于所有共享硬件状态均已隔离。
- 已知部署基线为QDC507/Baiwang模块内核3.18.44与Unraid内核6.1.126-Unraid；其他固件、内核或模块不在已验证支持矩阵。初次USB模式、ADB/UAC和运营商语音准备不是本仓库的一键安装功能。
- HiDeck参考版本2.1.23。服务的短期后台凭据适配依赖其HMAC配置格式；上游升级需要独立兼容验证，不使用latest自动升级。
- 本仓库不分发第三方驱动/固件；模块语音驱动的旧构建报告不能作为当前二进制对应源码证明。取得方式与校验见hardware.md。
- 原有中国号码规则包括国内手机号自动补+86。美区商店分发计划不能推出美国SIM、号码或运营商已验证。
- 新App身份已完成开发签名装机与前台接入；新版Sandbox锁屏来电、接听、双向声音和退后台通话已由用户确认；系统通话界面免提切换存在问题，修复候选真机复验仍回退、已延期；短信手机送达仍待验证，旧身份测试结论不直接继承。官方包的任意自托管锁屏来电需要尚未完成Production/TestFlight验收的推送中继，不能要求用户持有发布者私钥。
- App／服务0.1.1新增接通前音频，自动测试覆盖下行、上行隔离及录音边界；维护者已确认本轮接通前音频真机验证通过。结论限于现场环境，不保证所有运营商均提供播报；拒接、取消及锁屏回归尚未单独确认。
- 录音配置缺失/损坏时仍沿用既有开启行为；关闭需部署明确的false配置，不能删除文件代替关闭。
- 完整Go race/vet及iOS合成检查、模拟器编译已完成；新身份Sandbox开发包已获用户真实锁屏／通话反馈。正式0.1.0构建21已上传且Apple处理VALID，但Production／TestFlight真机、审核与商店发布未完成，公开GitHub源码已推送main。开发包不替代正式包验收。
- 来源元数据和发布清单提供追溯；自动签名正式归档／导出及上传已执行；构建attestation、商店审核及商店下载包等价验证未完成。正式构建必须通过独立TestFlight验收并使用同一构建提交审核。
