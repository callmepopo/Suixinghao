# 数据与隐私说明

本项目公开代码和通用部署方式，服务由用户自建。App只连接用户配置的HTTPS服务，不内置个人地址/账号/Key。GitHub与App Store提供源码/软件分发，不作为用户短信或电话数据服务器。

| 数据 | 保存位置与用途 | 公开要求 |
|---|---|---|
| 地址、App Key | iPhone本机Keychain，ThisDeviceOnly；服务仅Key摘要 | 不进文档、日志、截图；Key不放URL |
| 短信/联系人卡片信息 | 用户HiDeck数据库；授权接口响应含正文、号码、ICCID/IMSI等 | 只在功能中展示，问题报告替换合成值 |
| App通话记录 | 手机本机Keychain，按服务隔离，最多200条 | 可本机清空，不提供服务端历史查询 |
| 声音 | PCM通话链路；录音开关开启才保存WAV | 安装示例关闭录音，启用需参与者同意；文件名也含号码 |
| 连接/声音诊断 | 手机本机和自有服务，状态、时间、次数、数值 | 连接历史最多30天并有数量上限，无短信/声音/凭据 |
| APNs token | 用户服务私有文件，每Key每手机登记 | 不返回网页、不打印；撤销Key同步清理 |
| Apple私钥/签名 | 部署者宿主或本机私有签名资料 | 示例留空，永久不进仓库 |

自有数据目录0700，Key/令牌/配置/录音文件0600。录音每通最多1小时，目录总量1GiB滚动清理；这不自动涵盖备份里的留存。服务旧默认在录音配置缺失/损坏时开启，所以必须安装关闭配置，不能靠删文件停录音。反代访问日志需排除peer/iccid等查询值。

App通讯录授权用于本机号码搜索和来电姓名匹配，不上传整本通讯录；麦克风用于用户操作的通话，系统通知用于来电/新短信。VoIP推送仅含call_id，短信推送固定文案，Apple仍参与推送token和消息投递。生产商店版relay尚未实现，未来新增任何中心服务时必须重新说明token、路由标识、保留时间和访问权限，不能沿用“没有中心服务”的当前说明。

本文是源码的数据流说明，不能直接替代正式商店隐私政策和App Privacy问卷。正式上架前按实际构建、依赖与部署流程核对并提供公开政策/支持页，不填未验收的数据收集结论。日常测试资料留private/testing，生产材料留私有运行目录；private/legacy历史只读，公共源码始终单一仓库维护。
